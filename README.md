# analise-dados-policia
Projeto de Análise Exploratória de Dados (EDA) com dados da Polícia Rodoviária Federal (PRF) para identificar padrões de acidentes em rodovias brasileiras. Foram analisadas causas, localização, horários, clima e tipos de acidentes, gerando insights para apoiar ações de prevenção e segurança no trânsito utilizando Python e visualização de dados.
