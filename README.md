# Análise Exploratória de Acidentes em Rodovias Federais (PRF)

## 📌 Sobre o Projeto

Este projeto realiza uma **Análise Exploratória de Dados (EDA)** utilizando registros de acidentes da Polícia Rodoviária Federal (PRF), com o objetivo de identificar padrões que possam contribuir para a prevenção de acidentes e apoiar a tomada de decisão baseada em dados.

## 🎯 Objetivos

A análise busca responder às seguintes perguntas:

- Quais estados registram o maior número de acidentes?
- Quais são as principais causas dos acidentes?
- Em quais dias da semana e horários eles ocorrem com maior frequência?
- Como as condições climáticas influenciam a ocorrência de acidentes?
- Quais tipos de acidentes apresentam maior incidência e gravidade?

## 📊 Principais Resultados

- Minas Gerais, Santa Catarina e Paraná registraram o maior número de acidentes.
- A maioria dos acidentes ocorreu em condições de **céu claro**.
- Os acidentes concentram-se principalmente nos **finais de semana**, com pico entre **17h e 19h**.
- As causas mais frequentes foram **reação tardia ou ineficiente do condutor** e **velocidade incompatível**.
- **Colisões traseiras** e **saídas de leito carroçável** foram os tipos mais comuns, enquanto **colisões frontais** apresentaram o maior número de vítimas fatais.

## 📈 Conclusão

Este projeto demonstra técnicas de **limpeza, tratamento, análise exploratória de dados (EDA)** e **visualização de dados**, transformando dados públicos em insights que podem apoiar iniciativas de segurança viária e subsidiar decisões baseadas em evidências.
